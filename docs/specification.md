# Specification

## Problem and users

Agent systems routinely reuse support, operations and customer datasets for a new semantic purpose without proving that the requested fields, geography and lifetime remain inside the original covenant. Data stewards need a pre-effect control plane; analysts need a fast explanation and a recoverable path.

## Capability

Purpose Lattice registers data covenants, evaluates proposed processing plans, materializes field use through Apache Arrow, bounds semantic-purpose drift with split conformal calibration, propagates sensitivity through an information-flow lattice, recalls analogue decisions through RuVector, and writes allowed results to RVF. No single ingredient supplies that composed capability.

## Success

The browser must complete three journeys: allowed plan, denied plan with zero forbidden append and corrected recovery, and audit retrieval after refresh/restart. Success also requires 24 linked crates, real upstream calls, strict validation, reproducible launch, benchmark, ablations and exact-source evidence.
